# 🖨️ What is 3D Printing?

<span class="badge badge-3d">3D Printing</span>

A 3D printer builds objects **layer by layer** — like stacking thousands of thin slices on top of each other until you have a real object you can hold.

It turns a **digital design** (a file on a computer) into a **physical thing** you can hold.
